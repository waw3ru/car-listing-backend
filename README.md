# Car Listing API

> Offers services for cars that are on sale

## How to set up

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run start:dev
```

This project was created using `bun init` in bun v1.2.3. [Bun](https://bun.sh) is a fast all-in-one JavaScript runtime.

### Environments Required

```bash
NODE_ENV= #REQUIRED
SYS_USER= #REQUIRED
SYS_PASS= #REQUIRED
PORT= # REQUIRED
```
